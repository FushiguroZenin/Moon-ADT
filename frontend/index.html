MOON DOCUMENTATION

A local agent that explains before it acts.

Moon combines Dera1.4’s deterministic computer tools with a local language model. It observes, investigates, proposes, asks, and verifies.

Get connected

Start Moon’s local runtime, then open the Moon address in your browser. The dashboard talks to Dera1.4 on the same computer.

python run_api.py

Install locally

Moon installs as a local Windows runtime. Diagnostics work immediately; local AI is an optional setup choice.

Local AI with Ollama

Choose Enable local AI during setup for more natural conversation and clearer evidence explanations. Moon detects Ollama, guides the installation, and then downloads its recommended private model only after you confirm.

The model remains on the PC. It needs several GB of disk space and uses additional RAM while active, so diagnostics-only mode is a good lighter option.

What Moon can do

  • Read system status and investigate performance
  • Inspect Downloads and large folders
  • Review startup applications and crash evidence
  • Monitor meaningful local changes
  • Give safe manual guidance for sensitive tasks

Using Moon

  1. Ask a plain-language question.
  2. Review the evidence behind its answer.
  3. Follow a recommendation or ask a follow-up.
  4. For sensitive work, follow Moon’s recommended manual steps.

Local connection guide

The current Moon interface is local. Future web access will pair with the local runtime through an outbound relay, so a computer is never directly exposed to the public internet.

Known limits

Moon only supports its listed safe investigations. Results reflect the available local evidence, not a guaranteed root cause. It does not silently repair, delete, replace, or alter files.

PERMISSIONS AND CONTROL

You stay in control of every computer change.

Moon can observe and explain automatically. It cannot alter files, settings, or applications simply because a user asked in chat.

Observe→Investigate→Propose→Approve→Execute→Verify

What Moon may do automatically

Moon and Dera1.4 may collect read-only system evidence: performance values, storage use, process information, startup entries, event-log evidence, and folder sizes inside its allowed scope.

What always needs permission

Moves and copies require a specific proposal, an existing destination, a dry-run preview, explicit approval, and a separate execution action. Each operation is verified afterward.

What Moon does not do

Moon does not silently delete, overwrite, replace, close applications, alter settings, or execute unapproved commands. Those capabilities are not part of the current product flow.

How Dera1.4 protects the boundary

Dera1.4 chooses the allowed tool, validates paths and destinations, records proposal state, and verifies the result. The language model explains evidence but cannot bypass these controls.

What granting access means

Allowing Moon to run locally gives Dera1.4 visibility into the information needed for the investigation you request, such as system state, selected folders, or Windows event logs. A future paired web connection would route requests to this local runtime; it would not give a website unrestricted access to a computer. Only grant access on a computer you trust, review every proposal, and keep the local runtime and model environment secure.
