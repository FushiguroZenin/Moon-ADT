RELEASE NOTES

0.1.0 — Paired beta

Moon now combines local Dera1.4 diagnostics, grounded optional local AI, a Windows installer, and an opt-in paired web companion.

  • Live read-only CPU, memory, storage, network, and uptime snapshots on paired devices.
  • Evidence-backed local chat, diagnostics, monitoring, proposal review, and permissions.
  • Outbound-only relay pairing; the PC is never exposed as a public server.

Known limits

Remote deep investigations are still evolving. Moon V1 does not delete, overwrite, silently edit files, or perform unattended actions.
